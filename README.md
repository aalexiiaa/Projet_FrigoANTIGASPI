  Cette application vise à lutter contre le gaspillage alimentaire, une cause majeure du dérèglement climatique. Elle sert de hub de gestion pour une collectivité (foyer étudiant, association, cantine).
  L’utilisateur peut enregistrer les aliments présents dans le frigo avec leurs dates de péremption. L’application priorise automatiquement les produits à consommer afin d’éviter de jeter.
  Elle propose également des recettes basées uniquement sur les restes disponibles et permet de visualiser les économies de CO₂ réalisées grâce à une meilleure gestion alimentaire.
